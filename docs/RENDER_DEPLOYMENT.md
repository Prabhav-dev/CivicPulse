# Deploying CivicPulse to Render

This guide walks through deploying CivicPulse and its web user interface to [Render](https://render.com) as a Web Service.

---

## Architecture on Render

When deployed to Render, CivicPulse runs as a cloud web application:
- **Web UI & REST API:** Served by Javalin on port `$PORT` (Render defaults to `10000` or dynamically assigned).
- **Health Checks:** Native `/health` endpoint returning JSON HTTP 200 for Render zero-downtime deployment probes.
- **Dynamic Bind Address:** Automatically binds to `0.0.0.0` when deployed on Render (`PORT` or `RENDER` env detected).
- **Integrated Fleet Simulator:** Telemetry source streams simulated sensor data in-process or via loopback.
- **AI Alerting:** Integrates with Google Gemini via `GEMINI_API_KEY` (falls back automatically to deterministic local templates if key is omitted).

---

## Method 1: Deploy with Render Blueprint (Recommended)

CivicPulse includes a preconfigured [`render.yaml`](../render.yaml) blueprint specification for one-click setup.

1. Push this repository to **GitHub** or **GitLab**.
2. Log in to your [Render Dashboard](https://dashboard.render.com/).
3. Click **New +** > **Blueprint**.
4. Connect your CivicPulse repository.
5. Render will automatically parse `render.yaml` and configure:
   - **Service Name:** `civicpulse`
   - **Runtime:** `docker`
   - **Health Check Path:** `/health`
   - **Environment Variables:** Auto-generated keys for `CIVICPULSE_ANONYMIZER_SALT` and `CIVICPULSE_YGGDRASIL_KEY`.
6. (Optional) Provide your `GEMINI_API_KEY` in the Render environment settings to enable Gemini-powered maintenance suggestions.
7. Click **Apply**. Render will build the Docker image and deploy your web app.

---

## Method 2: Manual Web Service Setup (Docker)

If you prefer setting up the Web Service manually:

1. In the Render Dashboard, click **New +** > **Web Service**.
2. Select your repository.
3. Configure the following settings:
   - **Name:** `civicpulse`
   - **Region:** Choose the region closest to you.
   - **Branch:** `main` (or your active branch).
   - **Runtime:** `Docker` (Render will automatically detect the root `Dockerfile`).
   - **Plan:** `Free` (or higher).
4. Under **Advanced Settings**:
   - **Health Check Path:** `/health`
5. Under **Environment Variables**, add:

| Variable | Value / Description | Required? |
|---|---|---|
| `PORT` | `10000` (Render default) | Auto-injected by Render |
| `HOST` | `0.0.0.0` | Defaulted automatically |
| `GEMINI_API_KEY` | Your Google Gemini API key | Optional (uses template fallback if unset) |
| `CIVICPULSE_API_KEY` | Secret token required for `/sim/inject` and `/deltas` | Optional (demo mode if unset) |
| `CIVICPULSE_ANONYMIZER_SALT` | 32+ character random string | Optional in demo mode |
| `CIVICPULSE_YGGDRASIL_KEY` | 32 hex characters (e.g. `00112233445566778899aabbccddeeff`) | Optional in demo mode |

6. Click **Create Web Service**.

## Method 3: Manual Web Service Setup (Render Native Environment)

If you wish to use Render's native Java environment without Docker:

- **Runtime:** `Java`
- **Build Command:** `mvn clean package -DskipTests`
- **Start Command:** `java -XX:+UseG1GC -XX:MaxRAMPercentage=75.0 -jar target/civicpulse.jar`
- **Health Check Path:** `/health`

## Using the Web User Interface

Once deployed, visit your Render URL: `https://<your-service-name>.onrender.com`

The web application provides:
1. **Live Node Grid:** Real-time vibration RMS ($g$), temperature ($^\circ\text{C}$), RF power ($dB$), and telemetry freshness status across bridges, tunnels, towers, and sub-stations.
2. **Delta Inspector:** Click on any node card to open the detail modal and review recorded baseline deltas in real-time.
3. **Maintenance Alerts Feed:** View real-time alert logs generated by Gemini AI or the deterministic template fallback.
4. **Interactive Anomaly Injection:** Inject vibration spikes, freeze drops, sensor drifts, or dropouts directly into reporting nodes from the browser.
5. **API Key Integration:** If `CIVICPULSE_API_KEY` is configured in Render, click the 🔑 **API Key** button in the UI header to save your key in browser `localStorage`.
